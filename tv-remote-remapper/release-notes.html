Release Notes — TV Remote Remapper

TV Remote Remapper v1.0 @ GitHub

What it does

  • Blocks or remaps the Netflix button on Nvidia Shield, Google TV Streamer, and Chromecast with Google TV remotes. No root required
  • Remap target picker: choose any launchable app, or block the button outright, with an optional toast confirmation

How it works

  • System-wide interception via AccessibilityService (no-root path, user-enabled in system settings)
  • Persistent foreground-service notification keeps the process alive; restarts on boot
  • In-app fallback while the settings UI has focus; key matcher covers codes 181, 190, 191, 199 and scan code 440

Settings

  • Preferences stored only on device (DataStore): blocking, toast, remap target
  • Interface in 32 locales, TV banner and icons included

Builds

  • Kotlin + Jetpack Compose, Gradle Kotlin DSL, minSdk 23
  • CI produces debug APK and release AAB with unit tests on every run
