Politique de confidentialité — NoctiMar

Dernière mise à jour : 1er octobre 2026. Contact via LinkedIn

Collecte de données

NoctiMar ne collecte aucune donnée personnelle. Pas d'analyse, pas de publicité, pas de suivi, pas de compte utilisateur. Le développeur ne reçoit rien de votre utilisation

Paramètres sur l'appareil

Votre configuration (profils, serveurs, clés API, filtres, options de tri) est stockée uniquement sur votre appareil — dans le stockage local sur mobile et bureau, ou dans le stockage du navigateur pour la version web. Rien n'est envoyé ni partagé

Connexions réseau

L'app se connecte directement depuis votre appareil aux serveurs que vous configurez (instances Sonarr, Radarr, Lidarr, Prowlarr, SABnzbd, NZBGet ou Tautulli que vous possédez ou administrez). Les clés API ne sont envoyées qu'à ces serveurs, via les connexions que vous configurez. Aucun trafic ne passe par le développeur ni par un tiers

Synchronisation auto-hébergée optionnelle

La synchronisation des sauvegardes est optionnelle et désactivée par défaut. Si vous l'activez, les sauvegardes sont chiffrées sur votre appareil avant envoi, puis stockées comme blocs opaques sur un serveur que vous hébergez vous-même, protégé par un jeton que vous choisissez. Le développeur ne peut pas lire vos sauvegardes et n'exploite aucun serveur

Autorisations

L'app ne demande aucune autorisation système spéciale. La version web utilise uniquement le stockage standard du navigateur. Rien ne quitte l'appareil hormis les connexions directes à vos propres serveurs décrites ci-dessus

Enfants

L'app est un utilitaire général de contrôle de serveurs multimédia, ne collecte rien et convient à tous les âges

Modifications

Tout changement de cette politique sera publié sur cette page avec la date mise à jour
