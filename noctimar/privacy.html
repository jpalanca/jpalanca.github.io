Privacy Policy — NoctiMar

Last updated: 1 October 2026. Contact via LinkedIn

Data collection

NoctiMar collects no personal data. There is no analytics, no advertising, no tracking, and no account system. The developer receives nothing from your use of the app

On-device settings

Your configuration (profiles, server hosts, API keys, filters, sorting options) is stored only on your device — in local app storage on mobile and desktop, or in your browser's local storage when used as a web app. It is never uploaded or shared

Network connections

The app connects directly from your device to servers you configure (Sonarr, Radarr, Lidarr, Prowlarr, SABnzbd, NZBGet, Tautulli instances that you own or administer). API keys you enter are sent only to those servers, using the connections you set up. No traffic passes through the developer or any third party

Optional self-hosted sync

Backup sync is optional and off by default. If you enable it, backups are encrypted on your device before upload and stored as opaque blobs on a sync server you host yourself, protected by a token you choose. The developer cannot read your backups and operates no sync server

Permissions

The app requests no special system permissions. The web version uses only standard browser storage. No data leaves the device except the direct connections to your own servers described above

Children

The app is a general-utility media-server controller, collects nothing, and is safe for all ages

Changes

Any change to this policy will be published on this page with an updated date
