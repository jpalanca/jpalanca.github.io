Release Notes — NoctiMar

NoctiMar v1.0 @ GitHub

NoctiMar is a revival of LunaSea, the open-source self-hosted media controller archived in April 2025. NoctiMar continues with the same idea of one remote control for every self-hosted media service on your network (Sonarr, Radarr, Lidarr, Prowlarr, SABnzbd, NZBGet, Tautulli at the moment) rebuilt on a current Flutter stack, rebranded under a new nocti convention, and extended with a Docker web build and an optional private personal server config sync so it runs anywhere from your phone to your NAS

What's New

  • Added Prowlarr support

Backup and restore from your own server

  • NoctiMar can now run in Docker on any host or IP address, no cloud service needed
  • NAS sync service: Settings System gains host, token, upload, and restore, with deployment auto-fill while fields sit empty
  • Uploads mirror to a shared blob, so fresh installs restore too
  • SABnzbd works through a same-origin proxy path, so browser builds avoid connection errors

General

  • The menu shows the app version at the bottom. Old builds turn it into a tappable update note, and the check re-runs on every navigation
  • Backup import on web uses a native file dialog with visible failure feedback instead of silent hangs
  • Failed list pages retry with a tap on the error icon instead of requiring a full pull-down refresh

Sonarr

  • Season view from Missing or Upcoming shows a TV button jumping straight to that series Seasons list

Improvements

Technology stack

  • Direct dependencies moved from the archived upstream pins to current releases, including 13 major upgrades.   • Pagination and sharing flows were rewritten for the new APIs with no behavior loss. Code generation repaired for the current Dart toolchain. Remaining generators were already current

Speed

  • Poster and backdrop images decode capped sizes with a bounded image cache, cutting scroll jank on large libraries. Catalogue searches reuse memoized results, lists build rows lazily, and calendar, schedule, and log screens cache repeated work

Look and wording

  • Issue templates, funding page, and support links rebranded
  • Support links are placeholders until real community links exist
  • Internal identifiers renamed to the nocti convention

Removed

  • Discontinued Overseerr integration (service archived upstream). Settings no longer show it

Fixed

Sync and backup

  • Sync restore keeps host, token, and device id intact, even when the server copy is empty or stale
  • A missing server copy reports nothing to restore instead of failing
  • Web backup downloads preserve exact bytes for any file type

Editors and lists

  • Deleting a series returns to the originating tab, and removed shows vanish from lists instantly
  • Editors fall back gracefully when server profiles or entries were deleted elsewhere
  • Failed deletions no longer navigate away

Stability

  • Unreachable servers time out instead of spinning forever
