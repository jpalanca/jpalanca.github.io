Informativa sulla privacy — NoctiMar

Ultimo aggiornamento: 1 ottobre 2026. Contatto via LinkedIn

Raccolta dati

NoctiMar non raccoglie alcun dato personale. Nessuna analisi, nessuna pubblicità, nessun tracciamento, nessun account utente. Lo sviluppatore non riceve nulla dal tuo utilizzo dell'app

Impostazioni sul dispositivo

La tua configurazione (profili, server, chiavi API, filtri, opzioni di ordinamento) è salvata solo sul tuo dispositivo — nell'archivio locale su mobile e desktop, o nell'archivio del browser nella versione web. Nulla viene caricato o condiviso

Connessioni di rete

L'app si connette direttamente dal tuo dispositivo ai server che configuri (istanze Sonarr, Radarr, Lidarr, Prowlarr, SABnzbd, NZBGet o Tautulli di tua proprietà o da te amministrate). Le chiavi API vengono inviate solo a tali server, tramite le connessioni da te configurate. Nessun traffico passa dallo sviluppatore né da terze parti

Sincronizzazione self-hosted opzionale

La sincronizzazione dei backup è opzionale e disattivata per impostazione predefinita. Se la attivi, i backup vengono cifrati sul tuo dispositivo prima del caricamento e archiviati come blocchi opachi su un server di sincronizzazione ospitato da te, protetto da un token di tua scelta. Lo sviluppatore non può leggere i tuoi backup e non gestisce alcun server

Permessi

L'app non richiede permessi di sistema speciali. La versione web usa solo l'archivio standard del browser. Nulla lascia il dispositivo salvo le connessioni dirette ai tuoi server descritte sopra

Minori

L'app è uno strumento generale di controllo dei server multimediali, non raccoglie nulla ed è adatta a tutte le età

Modifiche
